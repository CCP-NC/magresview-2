# Average groups use tensor-averaged dipolar couplings

When an average group (CH3, NH2, ...) is collapsed to a single site, MagresView averages the
magnetic shielding and electric field gradient tensors arithmetically over the group's members —
matching Soprano — but computes each dipolar coupling to an external site as the mean of the
dipolar tensors from every group member, rather than from a single representative position.
Intra-group couplings are dropped.

Status: accepted

## Context

Soprano is the oracle for spin system export. Its `average_group` pipeline
(`soprano/nmr/extract.py:185`, `soprano/utils.py:73`) averages `ms` and `efg` with `merge_mean`
but takes `positions` from the first group member, so the dipolar couplings that follow are
computed from one arbitrarily chosen proton and are not motionally averaged at all.

Averaging the MS and EFG tensors over a C3-related methyl is the correct fast-rotation average,
because the rotation merely permutes the three sites. The dipolar couplings are the part Soprano
leaves unaveraged, and they are the part that dominates 1H spectra of organic solids. Exporting
static methyl dipolar couplings produces a spin system that is wrong at any realistic temperature.

## Considered options

**Match Soprano exactly.** Representative position, no dipolar averaging. Preserves an end-to-end
diff against Soprano's CLI output. Rejected: it knowingly ships the wrong physics for one of the
two primary use cases.

**Soprano's residual-rotation formula.** Soprano already implements the continuous-rotation
residual tensor in `_dip_tensor(d, r, rotation_axis)` (`soprano/nmr/utils.py:174`), but does not
wire it into the averaging path. Rejected: it requires constructing a rotation axis, which is
ill-defined for `XH2` patterns, and n-fold jump averaging only coincides with continuous-rotation
averaging for a rank-2 tensor when n >= 3. Applying it to an NH2 would be less correct than
Soprano while appearing more sophisticated.

**Tensor averaging over group members (chosen).** The dipolar coupling from an average group to an
external site is the mean of the dipolar tensors computed from each member position. This needs no
rotation axis, is the n-site jump average for any n, and reduces analytically to the residual
formula for an ideal C3 group.

## Consequences

- MagresView's spin system export no longer matches Soprano's end-to-end output whenever average
  groups are in use. The oracle survives at function level: reference values for the ideal-C3 case
  are generated by calling Soprano's `_dip_tensor(..., rotation_axis=...)` directly.
- Collapsing a group to one site leaves its internal couplings with nowhere to go. They are dropped
  rather than silently folded in, and the interface says so, because a user comparing spin counts
  against the structure will otherwise think sites went missing.
- If Soprano later adopts the same treatment, this divergence should be retired.
