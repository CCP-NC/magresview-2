# Axial tensors get a discrete, gauged Euler solution

An axially symmetric (non-spherical) tensor has a well-defined relative orientation to another tensor; its symmetry only frees the rotation about its unique axis. We therefore treat axial pairs as **discrete**, gauging that free rotation to zero, rather than as an angle-less "continuous" family. Following Svenningsson & Mueller (TensorView), when the unique axis lies on the PAS Z the free angle is simply the last Euler rotation (γ, active) for an axial target or the first (α, active) for an axial source — set to 0 — and β is the angle of/between the unique axis/axes; both axial gives (0, β, 0). The 16 PAS-frame configurations are de-duplicated by the drawn frames (an axial tensor's arbitrary transverse gauge is canonicalised), collapsing the degenerate-plane flips while keeping unique-axis sign flips, giving 8 configurations when one tensor is axial and 4 when both are. The gauged angle's arc is hidden and the reference-gauge ring marks the free rotation.

The clean single-angle gauge exists only when the unique axis is on Z, which every natural ordering provides (Haeberlen for MS, NQR for EFG, and the dipolar tensor by construction), so those are the per-tensor default orderings. When a user selects an ordering that places the unique axis on X there is no simple single-angle gauge (the paper's "non-intuitive symmetry line"); rather than emit non-reproducible angles we fall back to the static `continuous` display and warn, recommending the tensor's natural ordering. Only the spherical case remains `indeterminate`.
