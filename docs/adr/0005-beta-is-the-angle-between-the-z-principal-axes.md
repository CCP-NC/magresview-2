# Beta is the angle between the z principal axes (intrinsic convention)

The relative rotation that the Euler angles decompose is the source-frame *intrinsic* rotation `sourceᵀ·target` (its transpose for the passive sense), not the lab-frame rotation `target·sourceᵀ`. Expressed in the source PAS frame, the z-y-z / z-x-z decomposition makes β exactly the angle between the source and target z principal axes, so the rendered arcs land on the displayed axes: α about z_A from the reference axis to the line of nodes, β about the node from z_A to z_B, γ about z_B from the node to the reference axis. This is the standard NMR relative-orientation convention and is what lets a single object drive both the table and the geometry (see ADR-0002). The earlier lab-frame form self-reconstructed but drew arcs that did not map onto the axes. The convention is guarded by an independent round-trip test in `crystvis-js` (`test/relative-orientation.js`, `test/euler-disks.js`): for every PAS-frame configuration β equals `angle(z_A, z_B)` and the reported angles rebuild the intrinsic rotation via an independent textbook decomposition.
