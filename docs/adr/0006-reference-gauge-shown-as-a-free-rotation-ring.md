# The reference gauge is shown as a free-rotation ring

For an axially symmetric (degenerate) PAS the transverse principal axes are physically undetermined — the relative orientation is a `continuous` free rotation about the unique axis, with no discrete Euler-angle set. The geometry is drawn statically (both PAS frames, arcs and line of nodes hidden), and to stop the user reading meaning into the arbitrary transverse axes, a ring encircling the axial tensor's unique axis is shown to make the free rotation (the reference gauge) explicit. The ring is a child of the disk group so it inherits the frame orientation, is tilted to encircle whichever local axis is unique (0/x or 2/z, per the eigenvalue ordering), and is hidden in the discrete case and during configuration animation. The spherical (`indeterminate`) case remains a message with no disks. This is a lightweight visual cue rather than an interactive gauge control; letting the user spin the gauge is deferred until there is a concrete need.
